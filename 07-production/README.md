## ข้อมูลที่ควรมีเมื่อเปิดงานใหม่

- เป้าหมายและขอบเขต พร้อมลิงก์ข้อกำหนดต้นทาง
- dependency และประเด็นเปิดที่ต้องตอบก่อน
- ผู้รับผิดชอบและกำหนดเวลาเมื่อทราบจริง
- เกณฑ์รับงานและวิธีทดสอบที่สอดคล้องกับผลลัพธ์
- ลิงก์ชิ้นงานและผลทดสอบเมื่อส่งมอบ
