# S9 v0.6.3 — แสง วัสดุ อาคารและต้นไม้

วันที่ 2026-10-14 · [เปิดเกม](http://127.0.0.1:8765/src/) · [ภาพเทียบก่อน–หลังและภาพอ้างอิง](../../art/s9-pho-nimit/realism-review.html)

ปรับฉากจาก v0.6.2 เพื่อลดพุ่มไม้ทรงตัน ผนังสีเรียบและอาคารที่มีรูปทรงซ้ำ โดยเทียบ REF-03 / REF-06 / REF-08 ใน [ชุดภาพเดิม](../../art/s9-pho-nimit/references/README.md) ภาพเป็นข้อมูลปี 2023 ไม่ใช่การยืนยันสภาพปัจจุบัน มิติ ชนิดต้นไม้ และรายละเอียดอาคารยังเป็นการตีความ

## สิ่งที่เปลี่ยน

| ส่วน | การปรับ | เหตุผลจากภาพ |
|---|---|---|
| แสง | แสงกลางวันสีเป็นกลาง แสงเติมจากท้องฟ้า เงาและระยะหมอกใหม่ พร้อม environment สำหรับการสะท้อน | ภาพมีท้องฟ้าสว่างและแสงใต้ชายคาที่ต่างจากพื้นที่เปิด ไม่ใช่แสงเขียวเรียบทั้งฉาก |
| วัสดุ | Normal/roughness maps สำหรับปูน ถนน ตลิ่งและเปลือกไม้; กระจกมีม่านและความต่างของห้อง 4 แบบ | ผนังมีคราบ ผิวถนนและคอนกรีตไม่เรียบสนิท หน้าต่างไม่ได้ดำเท่ากันทุกบาน |
| อาคาร | ขอบมนตามหน่วยเมตร ราวดาดฟ้า ห้องบนหลังคา บังแดดหน้าต่าง ชั้นดาดฟ้าถอยร่นและครีบอาคารสูง; กระถางและถังเปลี่ยนจากเหลี่ยมเป็นทรงกลม | ชายคา หน้าต่างและงานระบบทำให้แนวอาคารจริงมีชั้นความลึกและ silhouette ที่ไม่ใช่กล่องเดียว |
| ต้นไม้ | เปลี่ยนพุ่มเดิม 156 instances เป็นกลุ่มใบที่มีช่องโปร่ง 3 แบบ เพิ่มกิ่งแยกและผิวเปลือก | มองเห็นใบย่อย ช่องว่างระหว่างกิ่ง และเส้นขอบพุ่มไม่สม่ำเสมอ |
| การวาดภาพ | พักวาดเมื่อกล้อง/ฉากอยู่นิ่ง และลดการสร้าง shadow map ซ้ำ; ยังวาดตาม animation frame ขณะตัวละครเดิน | ลดภาระจากใบไม้และ texture ที่ละเอียดขึ้น โดยคงเวลาและกฎ simulation เดิม |

แสงเป็นการจัดจากลักษณะภาพ ไม่ใช่ HDR ที่วัดหน้างาน Texture ทั้งหมดสร้างจากสคริปต์ ไม่มีพิกเซลภาพถ่ายฝังในโมเดล ดู [source](../../art/s9-pho-nimit/realism_model.py), [lighting](../../src/game/daylight.mjs) และ [spec](../../art/s9-pho-nimit/realism/realism-spec.json)

## ผลตรวจ

**Automated 28/28 ผ่าน** ครอบคลุม navigation, placement, การขนส่ง/ยอดเสบียง, pause/speed, save/load บนบันได, migration, การใช้งานประจำวัน และ checks ใหม่สำหรับใบโปร่ง ขอบมน วัสดุที่ผูกกับ mesh จริง tangent frame และ clearance

**Khronos glTF Validator: 0 errors / 0 warnings / 0 infos / 0 hints** ส่งออก tangent frame ไว้ในไฟล์สำหรับทุกวัสดุที่ใช้ normal map ไม่ต้องพึ่งการสร้าง tangent ต่างกันระหว่างโปรแกรม

Browser QA ใช้ `/src/?qa=1` แยกเซฟจากผู้เล่น โหลด `s9-realism-v063` และแสง `s9-neutral-daylight-v063` ทดสอบถอน/วาง P9, P10 และ P5 รีโหลดขณะที่พนักงานถืออาหารรวม 24 หน่วย และตรวจส่งต่อจนจบ ข้อมูลเวลา ตำแหน่ง งานและ cargo ก่อน/หลังรีโหลดตรงกัน รายละเอียดผลสุดท้ายอยู่ใน [browser evidence](2026-10-14-s9-realism/browser-evidence.json)

จบที่ **49 เที่ยวจากเดิม 38 เที่ยว**: 9 เที่ยวสำหรับจุดที่ติดตั้งใหม่ และ 2 เที่ยวเติมหลังข้ามวัน จุดอาหาร/น้ำทั้ง 6 จุดเต็ม 24/24 พนักงานกลับคลังครบ คลังเหลืออาหาร 13 น้ำ 6 อะไหล่ 40 ใน [เซฟที่ส่งออกจากเบราว์เซอร์](2026-10-14-s9-realism/completed-save.json) ยอดใช้สะสมอาหาร 10 น้ำ 12 ทำให้ `13 + 72 + 10 = 95` และ `6 + 72 + 12 = 90` ตรงยอดตั้งต้น ไม่เกิดเสบียงเพิ่มหรือสูญหาย

ตรวจตัวนับเฟรมสองครั้งขณะหยุดแล้วเท่ากัน และเปลี่ยนมุม/ชั้นแล้วตัวนับเพิ่มพร้อมภาพใหม่ เป็นหลักฐานการพักเรนเดอร์ ไม่ใช่ผล benchmark FPS

ตรวจมุมภาพรวม ถนน/คลอง หน้าร้าน และมุมตัดชั้น แก้ใบที่หายเมื่อย่อ texture และทิศของ sky environment จากการตรวจภาพจริง ระหว่างควบคุมเบราว์เซอร์มี mouse dispatch timeout จึงใช้คีย์บอร์ดกับปุ่มมาตรฐานต่อ โดยไม่ได้เรียก simulation หรือแก้เซฟผ่าน JavaScript
