# 03 · เนื้อเรื่องและโลกนิยาย

[กลับสารบัญ](../README.md)

เอกสารหลัก: [Campaign 01: Bangkok Outbreak — Story Canon](LAND_OF_SMILES_STORY_CANON_v1_TH.md)

ใช้เก็บ world bible, timeline, ตัวละคร กลุ่มอำนาจ บทสนทนา และเนื้อหาเหตุการณ์ โดยแยก **Canon**, **สมมติฐานที่ตัวละครเชื่อ** และ **ข้อเสนอของผู้เขียน** ออกจากกัน

| ต้องการอ่าน | ส่วนใน Story Canon |
|---|---|
| Logline และแกนเรื่อง | 1–2 |
| H-08 และภูมิหลังวิกฤต | 3 |
| ภูมิศาสตร์น้ำท่วมและข้อมูลโรคในโลกนิยาย | 4–5 |
| ไทม์ไลน์ DAY 0–14 | 6 |
| รัฐบาล เส้นทางอพยพ และความขัดแย้ง | 7–8 |
| โครงเรื่องและปมที่ยังเปิด | 9–10 |
| Canon ที่ต้องรักษาเมื่อเขียนต่อ | 11 |

ต้นฉบับใช้ Story Canon **v0.2** และ Brand Adaptation **v1.0** เหตุการณ์และสมมติฐานในโลกนิยายไม่ใช่ข้อมูลสถานการณ์จริง

ก่อนเพิ่มภารกิจ ให้ตรวจผลต่อ timeline และ Canon; กฎเชิงระบบของภารกิจอยู่ [Game Design](../02-game-design/README.md) ส่วนพื้นที่และลำดับการเรียนรู้อยู่ [World & Levels](../04-world-and-levels/README.md) ประเด็นที่ต้องตัดสินใจร่วมกันบันทึกที่ [Production](../07-production/open-decisions.md)
