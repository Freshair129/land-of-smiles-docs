# แม่แบบเอกสาร

[กลับสารบัญ](../README.md)

คัดลอกแม่แบบไปยังหมวดที่เกี่ยวข้องแล้วตั้งชื่อให้สื่อเรื่อง เก็บไฟล์ในโฟลเดอร์นี้ไว้เป็นแม่แบบกลาง และเติมลิงก์แหล่งอ้างอิงของเอกสารใหม่ตามตำแหน่งจริง

| แม่แบบ | ใช้เมื่อ | หมวดปลายทาง |
|---|---|---|
| [Feature Spec](feature-spec.md) | ออกแบบระบบ กฎ หรือพฤติกรรมหน้าจอ | Game Design หรือ Art & UX |
| [Level Brief](level-brief.md) | ออกแบบฉาก ภารกิจพื้นที่ หรือ tutorial | World & Levels |
| [Decision Record](decision-record.md) | เปรียบเทียบทางเลือกและบันทึกคำตัดสิน | Production |
| [Playtest Report](playtest-report.md) | เตรียมทดลองและเก็บผล playtest/QA | Playtesting |

ช่องที่ยังไม่มีข้อมูลใช้ “ยังไม่ระบุ” และคงสถานะ Draft หรือ Not run ตามชนิดข้อมูล จนกว่าจะมีคำตัดสินหรือหลักฐานจริง
